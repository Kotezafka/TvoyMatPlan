# Локальный запуск TutorPlatform

Обычный `docker compose up -d` поднимает сайт, API, базу, LiveKit и локальные AI-сервисы на компьютере. Cloudflare Tunnel и VPS не используются.

На компьютере сайт открывается по адресу:

`http://localhost:3004`

Для устройств в той же домашней сети:

`http://192.168.3.8:3004`

Для подключения камеры телефона через локальный HTTPS-шлюз:

`https://192.168.3.8:3443`

Порты 3001, 3004, 7890/TCP, 7891/TCP и 7892/UDP должны быть доступны через Windows/WSL firewall. LiveKit объявляет локальный адрес `192.168.3.8`, чтобы видеопоток между устройствами в одной сети шёл напрямую.

```bash
docker compose ps
curl http://localhost:3001/api/health
```

## Камера телефона

Мобильные браузеры разрешают доступ к камере только на `localhost` или через HTTPS. При первом открытии локального адреса браузер покажет предупреждение о самоподписанном сертификате; его нужно принять на телефоне. Публичные туннели для сайта не требуются.

Для временного удалённого доступа Cloudflare можно включить явно отдельным compose-файлом; он не запускается командой `docker compose up -d`.
