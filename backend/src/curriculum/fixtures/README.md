# Учебный банк синтетических задач

`deepmind-math.v1.ts` содержит 300 задач для тренировки арифметики и алгебры:
по 100 для ОГЭ, базового ЕГЭ и профильного ЕГЭ. Каждая формулировка переведена
на русский, а задания имеют числовые ответы для автоматической проверки.

Задания получены запуском генераторов из **Mathematics Dataset** DeepMind, а не
скопированы из официальных экзаменационных вариантов. Исходный генератор
зафиксирован на commit `427f45075f84b8b9774950196ad63867ca20ffb3` и
распространяется по лицензии Apache License 2.0. Полный текст лицензии находится
в [`licenses/APACHE-2.0.txt`](licenses/APACHE-2.0.txt).

Источник: [google-deepmind/mathematics_dataset](https://github.com/google-deepmind/mathematics_dataset)
Авторы набора: DeepMind Technologies Limited. Научная статья: Saxton et al.,
[Analysing Mathematical Reasoning Abilities of Neural Models](https://openreview.net/pdf?id=H1gR5iR5FX).

Это учебный банк, не официальный КИМ и не полная модель спецификации ОГЭ или ЕГЭ.
Автоматически собранные наборы повторяют только поддерживаемые в проекте типы
числовых задач. Не добавляйте источник в метаданные как официальный ФИПИ.

## Пересборка

В окружении Python 3 с пакетами `numpy`, `six`, `sympy` и `absl-py` выполните:

```bash
python3 backend/scripts/generate_deepmind_math_bank.py
```

Скрипт скачает ровно закреплённый commit генератора и заново создаст TypeScript
каталог. Запуск сайта и генерация вариантов не требуют Python или доступа к
стороннему сайту: каталог включён в приложение и хранится в локальной базе.
